# LayerAnalyzer 1.1.0

Android 8.0（API 26）及以上，ARM64。应用 ID 保持 `com.layeranalyzer.android`，`versionCode` 从 4 增至 5。正式包使用与 v1.0.0 相同的签名证书，无需卸载旧版。

## 自 v1.0.0 起的主要变化

- **分析已有 TLS 抓包**：为 PCAP / PCAPNG 导入匹配的 NSS 会话密钥日志；可以在帧详情切换原始密文与派生明文字节，或跟踪整条 TLS 流。清除密钥会重新解析，不修改原始抓包。
- **按范围抓取 HTTPS**：VPN 抓包支持本地 TLS 1.2 / 1.3 over TCP 代理，可选择应用、域名和端口，并配置绕过规则。主动代理默认关闭。安装 CA 不代表所有应用都信任它；上游仍校验证书链及主机名。
- **重开与导出会话**：按会话管理分段抓包和保留的密钥。原始抓包导出默认不带密钥；完整可解密包和选定明文分别确认导出。AI 分析对解密内容另行执行隐私策略。
- **转发与分析界面**：VPN 改用有连接上限的非阻塞 SOCKS 转发，增加连接状态与抓包完整性提示。报文详情支持按数据源高亮；分析工具的卡片与列表样式统一。

用法及清理步骤见 [TLS 解密指南](https://github.com/cheig/LayerAnalyzer/blob/v1.1.0/docs/vpn_tls_decryption_usage.md)。请仅分析获授权的连接，不要在问题报告中上传会话密钥、CA 私钥或解密明文。

## 兼容性与已知限制

- 不主动解密 QUIC / HTTP/3、DTLS 或 STARTTLS，不绕过证书固定；不保证 mTLS、ECH 或 TLS-PSK。可选的 UDP/443 阻止也不能保证客户端回退 TCP。
- 原生依赖更新为 [Wireshark 4.0.10-r3](https://github.com/cheig/LayerAnalyzer_libs/releases/tag/wireshark-4.0.10-r3)，包含重建解析会话时的名称解析缓存修复，不是 Wireshark 安全升级。4.0 系列已停止维护，[既有安全风险](https://github.com/cheig/LayerAnalyzer/blob/v1.1.0/docs/wireshark-security-maintenance.md)仍然适用。
- 正式 APK 仅提供 ARM64。16 KiB 静态对齐检查不等于已在 16 KiB 页大小设备上运行。
