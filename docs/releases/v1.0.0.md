# LayerAnalyzer 1.0.0

适用于 Android 8.0（API 26）及以上的 ARM64 设备。

支持 PCAP/PCAPNG 导入、协议树与过滤、VPN 抓包、RTP 媒体分析与播放，
以及使用自配服务和 API 密钥的 AI 辅助分析。AI 服务需要用户自行配置。
versionCode 为 3，使用既有正式签名，可覆盖安装同签名的较早版本。

附件仅包含 `LayerAnalyzer-arm64-v8a-1.0.0.apk` 和 `SHA256SUMS`。
完整应用源码、原生源码、构建说明及许可材料的链接见本说明末尾。

## 验证范围

Actions 构建执行源码/许可检查、JVM 单元测试、原生 host 测试、双 ABI 开发构建，
以及 Release 单元测试、lint、正式签名和 ELF/APK 16 KB 对齐检查。
正式 APK 仅包含 ARM64；x86_64 是开发测试变体。

此前 Android 16 ARM64 候选包的核心流程验收通过，包括合成抓包、过滤/导出、
VPN 双向转发、AMR/H.264 媒体及许可/AI 设置界面。这不代表本次 1.0.0 APK 已完成设备验收。

自动构建先创建草稿；发布前请验证该草稿中的实际 APK 并补充结果：

## 已知问题与覆盖边界

- 使用固定 Wireshark 4.0.10 / r1 库及 r2 对应源码。4.0 系列已停止上游维护，
  当前库未回移已记录的安全补丁；8 项明确未修复、3 项待验证、109 项待审。
  详细状态见源码中的 `docs/wireshark-security-maintenance.md`。

  也曾触发原生崩溃。这两项尚未修复；已通过的核心应用流程遵循初始化门禁和单活动文件顺序。
- 未完成旧 Android 设备、真实远程 AI 和缺少外部 RTP 输入的完整设备套件验收。
